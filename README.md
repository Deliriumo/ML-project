# ML-project
# Обнаружение мошеннических транзакций по кредитным картам

## Описание проекта
Бинарная классификация транзакций на легитимные (0) и мошеннические (1) с использованием реального датасета Kaggle «Credit Card Fraud Detection».  
Цель — построить модель, которая эффективно выявляет фрод при сильном дисбалансе классов (0.17% мошенничеств).

## Структура репозитория
- `ml_project.ipynb` — Jupyter Notebook со всем анализом и кодом.
- `xgboost_model.pkl` — сохранённая лучшая модель XGBoost.
- `scaler.pkl` — обученный RobustScaler для признака Amount.
- `requirements.txt` — зависимости.
- `README.md` — этот файл.

## Данные
- Источник: [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) на Kaggle.
- Признаки: Time, Amount, 28 PCA-компонент (V1–V28), Class (целевой).
- Размер: 284 807 транзакций, из них 492 мошеннические.

## Основные этапы работы
1. **EDA** — анализ распределений, корреляций, визуализация баланса классов, временны́х паттернов.
2. **Предобработка** — масштабирование Amount (RobustScaler), создание признаков Hour, Amount_to_mean, V17_V12_interaction.
3. **Борьба с дисбалансом** — SMOTE и взвешивание классов (scale_pos_weight).
4. **Обучение моделей** — Logistic Regression (baseline), Random Forest, XGBoost.
5. **Подбор гиперпараметров** — GridSearchCV для XGBoost.
6. **Оценка** — ROC-AUC, Precision, Recall, F1, матрица ошибок.
7. **Интерпретация** — Feature importance, SHAP, partial dependence plots.
8. **Проверка гипотез** — ночной фрод, мелкие суммы, сравнение с правилами.

## Результаты лучшей модели (XGBoost)
| Метрика      | Значение |
|--------------|----------|
| ROC-AUC      | 0.982    |
| Recall       | 0.8776   |
| Precision    | 0.7478   |
| F1-score     | 0.8075   |

- **Матрица ошибок**: TN=56848, FP=16, FN=12, TP=86.
- Модель находит 88% мошенничеств при 0.03% ложных тревог.
